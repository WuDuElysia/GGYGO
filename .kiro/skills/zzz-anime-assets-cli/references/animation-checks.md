# 动画数据损失定位

按原始 AnimationClip→导出 FBX／中间文件→UE AnimSequence→运行时消费逐层定位，只核受影响项目，不为每项问题全量重导。

- 原源／导出物：时长、采样率／键范围、骨层级、根轨道、位移旋转曲线、普通曲线及事件来源。
- UE：实际 Skeleton／绑定、轨道／根级数据、时长／范围、导入与压缩设置、Root Motion，以及 AnimGraph／Montage 的真实使用。
- 有现成可信原导出不重复解包；需要补原源才按 CLI 获取。MCP 能读则用，未暴露项留未验证或走受支持只读原生工具，不说资产不存在。
- 分类为解包丢失、中间转换丢失、UE 导入差异或运行消费问题；预览相似／资产存在／编译通过都不能单独证明完整。
- 数值比较明确轴、单位、实际绑定及原生量化转换；不靠拟合／放宽阈值把差异消掉。

Pyrios TurnBack 若涉及根层级，分别核外部 Root 的 Rotation Y／Translation Z、Bone_Root→Bip001视觉链与 Bip001根级轨道，以及完整 pivot／跑出范围。Bone_Root yaw=0不证明源无转身，外部Root yaw也不直接证明角色骨架旋转。仅此类问题才展开这些特例。
