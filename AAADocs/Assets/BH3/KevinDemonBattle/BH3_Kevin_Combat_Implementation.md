# Kevin DemonBattle：Montage 与判定实施记录

## 目标与边界

仅使用已导入的 `/Game/Characters/Boss/Kevin/DemonBattle/`，先完成动作用途整理、适用的 Montage 资产和一组可验证近战攻击。不修改玩家普攻策略、Pyrios 渲染、当前主关卡，也不把其他 Kevin 形态引入本轮。

导出 JSON 提供帧率、根运动轨迹、循环等动画信息，不提供完整伤害/碰撞窗口。FBX 骨骼轨道是动作依据，不自动等于命中时间。来源事实、命名推断和人工候选配置必须分开标记；远程、召唤、投技、配对演出不伪装为武器扫掠。

## 模块分工与接口契约

**用户确认的代码/蓝图边界**：C++ 负责可复用架构、曲线/扫掠执行、权限、生命周期及安全校验；具体 Kevin 招式、动作组合、伤害/范围/位移参数、选招规则和表现放到 GA 蓝图、BT、ABP、Montage 与数据资产。不得在通用 C++ 中按 Kevin 动作名称写业务分支。编辑器批量生成器只生产/核验资产，不作为运行时业务控制器。

**用户确认的职责唯一性**：BossAI 选择目标/动作，不重复维护能力执行状态；GA 负责准入、生命周期、资源句柄和伤害 GE，不自行积分位移；Movement 唯一移动胶囊，不读 Boss 招式业务；Animation 负责姿态与窗口语义，不扣血或写胶囊；Combat 负责查询/去重，不决定招式时机或伤害数值。具体曲线由资产提供，原始动画剥除轨迹与 CMC 轨迹成对交付，禁止双重位移。

| 模块 | 负责内容 | 边界 |
| --- | --- | --- |
| Animation | 全部 75 条有效动作分类及 4 空片段说明；可配置动作清单；独立 Montage、Slot、ABP、窗口与生成工具；源骨骼/武器端点证据 | 不凭 AS/BS/Loop 后缀自动拼完整技能，不自动开启根位移，不写伤害执行代码 |
| Combat / BossAI | BossMelee 安全防护、判定及自动化；独立 Kevin GA/PawnData/ActionSet/Definition 接线与验证，引用动画模块交付的 ABP | 常改参数在 GA 蓝图和 Montage；AI 只请求 ActionTag，服务器能力应用伤害；不重复编辑 ABP 图 |
| Movement | Boss 攻击位移曲线、CMC 权威执行与动作结束清理；首批派生动画去重复位移及坐标验证 | 保留原始动画，不改变玩家移动，不让动画表现层决定权威位移 |
| 根协调 | 范围与数据契约、编辑器时段、统一构建、独立审核、全局笔记及中文 Git 提交 | 不覆盖模块编辑、不混入原有 Pyrios 未提交修改 |

复用 `UGGYGOAnimNotifyState_GameplayEventWindow` 的 `Event.Montage.HitWindowBegin/End`，以及 `UGGYGOBossMeleeAbility` 的 Montage、骨骼端点、半径、伤害与韧性伤害配置。第一版只使用不重叠的顺序命中窗口；同窗口同目标只命中一次，下一窗口可再次命中。窗口与骨骼动画必须由同一个当前 Montage 驱动，中断和 BlendOut 均关闭判定。

### 已确认的 Boss 位移选择

用户选择“和现在的角色操控很像，也做成曲线那种”。本轮增加 Boss 专属曲线动作位移：导出数据 → 曲线配置 → GA 生命周期 → CMC 权威执行。原始序列只读，另建首批近战的派生动画去除已交给胶囊的那部分位移，避免双重移动；坐标轴、单位、起始偏移、结束/取消清理须验证。此选择不解除玩家攻击位移策略的既有待确认状态。
