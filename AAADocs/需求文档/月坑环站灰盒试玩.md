# 月坑环站灰盒试玩

在 UE 5.9 副本中打开 `/Game/Map/LunarStation/L_LunarStation`，以当前关卡的 PlayerStart 开始 PIE。生产 Pyrios 从南站出生。沿正面通道先试闸门，再从西侧进入检修廊。下层短坡直达检修台，上层长坡经过看台后也可回到检修台。从闸门内侧踩上黄铜踏板，门叶横移 4.8 米，可折返外院。北侧双拱后的短廊通向独立地图 `/Game/Map/BH3/L_KevinBoss_P3`。

## 重现

在副本项目的 PowerShell 中运行以下命令，每次启动一个独立的编辑器实例。两条路线各从未开启的闸门重新开始，脚本通过工程的数字键输入桥操作 Pyrios。录像可选，传入本机 FFmpeg 可执行文件的路径后，脚本会把实际游戏视口录为每秒 6 帧的无声 MP4。

```powershell
.\AAADocs\Scripts\run_lunar_station.ps1 -Mode Lower
.\AAADocs\Scripts\run_lunar_station.ps1 -Mode Upper
.\AAADocs\Scripts\run_lunar_station.ps1 -Mode Upper -CheckReturn
```

录像参数为 `-FFmpeg <ffmpeg.exe 的完整路径>`。`-CheckReturn` 额外检查两处坡道的反向通行、短廊触发线前折返和前庭回望。每次输出位于 `Saved/Codex/LunarStation/<时间>_<路线>/`，包括 `walk.json`、编辑器日志、关键节点原始 PNG 和启用录像时的 MP4。地图已经制作完毕。仅在目标地图、机关蓝图及材质均为空的副本中使用 `-Mode Build` 重建。
